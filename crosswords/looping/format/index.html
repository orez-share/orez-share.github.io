Looping Crossword .ipuz Format

A looping crossword is a crossword puzzle where the edges of the crossword do not terminate clues: instead the clues loop over to the other side of the crossword.

Looping crosswords use the .ipuz file format for crosswords, with the following additions and considerations.

kind Field

The kind field must be an array containing the following values, in this order:

  • "http://ipuz.org/crossword#1"
  • "https://orez-share.github.io/crosswords/looping/format"

This allows software that is not aware of looping crosswords to fall back as a regular crossword. The kind array MAY contain other values if the puzzle contains other variant rules.

New Fields

"tessellation": { "x", "y" }
The offset of the tessellation loop. This field is required.
  • x must be an integer in the range [0, dimensions.width).
  • y must be an integer in the range [0, dimensions.height).
"viewport": { "width", "height" }
The dimensions of grid cells to display. If omitted, this field will default to the values from dimensions.

Grid Representation

When tessellation's x and y values are both nonzero, the x by y area at the bottom right of the grid representation will logically be identical to the cells in the top left of the grid.

Depiction of a 5x5 looping crossword with a 2x3 tessellation offset. The green area denotes the unique grid, and the yellow area at the bottom right denotes the overlap area resulting from the tessellation offset. In grid representations in the .ipuz file, the yellow region must match the top left of the green region.

Technically this means that it's representationally redundant to define the region of x by y cells at the bottom right. Despite this, all dimensions.width by dimensions.height cells MUST be defined, and they MUST logically match any duplicates. That is, the top left x by y cells must be identical to the bottom right x by y cells. This is to enable compatibility with traditional crossword solving tools.

This rule applies to all fields representing the grid, including puzzle and solution.
