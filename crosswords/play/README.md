# Build Script for [/crosswords/play](https://orez-share.github.io/crosswords/play)

Assumes you've got the [variant crossword player](https://github.com/orez-share/variant-crossword-player/) project code checked out sibling to the orez-share.github.io project.

The `./build.sh` script will build the variant crossword player code and replace the existing version of the app with the new build.
It will also commit the changes, but will not push them.
