What is a Peapod?

In a traditional crossword, each cell contains a single letter, and you read the fill cellwise left to right and top to bottom.

A peapod crossword (or just "peapod") is a crossword puzzle where each cell contains two letters. Otherwise, it's exactly like a traditional crossword!

🫛 Peapod Crossword Setter
A tool for setting peapod crosswords: crosswords where each cell contains 2-letter rebus.

The Peapod Crossword Setter allows for shaping a grid, suggesting potential fills, and exporting the result as an .ipuz file, which can be shared and run in your crossword solving tool of choice.

If you'd prefer to set a peapod by hand, you may instead view the peapod format spec.
