Peapod Crossword .ipuz Format

A peapod crossword is a crossword puzzle where each cell contains two letters.

Peapods use the .ipuz file format for crosswords. Peapods are entirely compatible with any crossword solving software that supports rebuses. However, the process for entering a rebus tends to require more thought and keypresses than simply typing an answer. Solving software that is aware of peapods may wish to adjust its presentation accordingly, eg to not advance the cursor until the cell contains the expected letter count.

kind Field

The kind field must be an array containing the following values, in this order:

  • "http://ipuz.org/crossword#1"
  • "https://orez-share.github.io/peapods/format"

This allows software that is not aware of peapods to fall back as a regular crossword. The kind array MAY contain other values if the puzzle contains other variant rules.

New Field

The peapod format has no required fields and only one optional field:

"lettersPerCell"
Number of letters per cell. If omitted, defaults to 2.
